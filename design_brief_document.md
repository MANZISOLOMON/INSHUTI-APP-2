# Design Brief Document

## 1. Overview
Defines the visual aesthetic, color tokens, typography, and component styling based on a clean, light, minimalist interface inspired by modern fintech layouts.

## 2. Brand Identity
Clean, trustworthy, light, and approachable. Minimalist cards with high readability, generous whitespace, soft grey structural dividers, and crisp forest green accents. Strictly NO dark-mode themes or heavy black canvas layouts.

## 3. Color Tokens

```
Canvas Background:  #F8FAF7  (Soft Off-White / Cream)
Card Background:    #FFFFFF  (Pure White Elevated Cards)
Primary Accent:     #1B4D3E  (Deep Forest Green)
Secondary Accent:   #2E7D5F  (Medium Forest Green)
Borders / Muted:    #E5E9E4  (Light Grey Accent Border)
Text Main:          #1A201C  (Dark Slate Charcoal)
Text Muted:         #65736B  (Soft Sage Grey)
Success / Escrow:   #10B981  (Emerald Green)
Danger / Alert:     #EF4444  (Muted Crimson)
```

## 4. Typography & Visual Hierarchy
* **Primary Font:** Inter / System Sans-Serif
* **H1 Heading:** Bold 32px / Line Height 40px
* **Card Titles:** Semi-Bold 18px
* **Badges / Masked Details:** Monospace font (`ID: 119988****521`)
* **Buttons:** Rounded full / Pill-shaped buttons (`rounded-full`), deep green background with white text (`bg-[#1B4D3E] text-white`).
